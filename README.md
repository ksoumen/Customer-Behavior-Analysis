# 🛍️ Customer Behavior Analysis – End-to-End Data Analytics Project

## 📌 Project Overview

This project presents a complete **End-to-End Data Analysis Workflow** focused on understanding customer shopping behavior using transactional data from **3,900 customer purchases**.

The objective is to extract actionable business insights related to:

- Customer Segmentation
- Revenue Trends
- Product Performance
- Subscription Behavior
- Discount Impact
- Age-Based Revenue Distribution

This project demonstrates a full analytics pipeline:

> **Python (EDA & Cleaning) → PostgreSQL (SQL Analysis) → Power BI (Dashboard) → Business Reporting → GitHub Deployment**

---

## 🔄 Project Workflow

![Project Workflow](Project%20path%20way.png)

### 🔹 Step 1 – Business Problem Definition
Defined key business questions related to customer behavior and revenue generation.

### 🔹 Step 2 – Data Cleaning & EDA (Python)
- Data loading using `pandas`
- Missing value handling (Review Rating imputed using median by category)
- Column standardization (snake_case)
- Feature engineering:
  - Created `age_group`
  - Created purchase frequency metrics
- Data validation & consistency checks
- Loaded cleaned data into PostgreSQL

### 🔹 Step 3 – SQL Business Analysis
Performed structured SQL analysis in PostgreSQL:

- Revenue by Gender  
- High-Spending Discount Users  
- Top Rated Products  
- Shipping Type Comparison  
- Subscriber vs Non-Subscriber Analysis  
- Discount-Dependent Products  
- Customer Segmentation (New / Returning / Loyal)  
- Top 3 Products per Category  
- Repeat Buyers & Subscription Correlation  
- Revenue by Age Group  

### 🔹 Step 4 – Power BI Dashboard
Built an interactive dashboard to visualize insights for stakeholders.

## 📈 Key Business Insights

- Clothing category generated the highest revenue.
- Young Adults contributed the highest total revenue.
- Only 27% of customers are subscribers — growth opportunity exists.
- Discount usage increases sales volume but requires margin optimization.
- Repeat buyers show higher subscription likelihood.

---

## 💡 Business Recommendations

- Promote subscription benefits to increase recurring revenue.
- Implement loyalty programs for repeat buyers.
- Optimize shipping strategies for high-spending segments.
- Review discount dependency to protect profit margins.
- Focus marketing efforts on high-revenue age groups.
